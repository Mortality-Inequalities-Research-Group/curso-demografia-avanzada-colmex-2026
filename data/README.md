# Datos

Esta carpeta contiene datos de práctica para los labs del curso.

## Día 1

- `dia-01/kitagawa-gfr-data.RData`: nacimientos y exposición para el ejercicio de descomposición de la tasa general de fecundidad.
- `dia-01/kitagawa-tfr-bonus-data.RData`: datos simulados para el ejercicio bonus de TFR por edad y situación de unión.

## Día 2

- `dia-02/yll-data.RData`: tabla de vida y distribución de muertes por edad y causa para el ejercicio de años de vida perdidos.
- `dia-02/arriaga-covid-usa-data.RData`: datos para la descomposición de Arriaga del cambio en esperanza de vida masculina en Estados Unidos entre 2019 y 2020.
