# curso-demografia-avanzada-colmex-2026
Materiales del curso de demografía avanzada, Colmex 2026

## Sitio web

Este repositorio usa [Quarto](https://quarto.org/) para generar el sitio web del curso.

Para construir el sitio localmente:

```bash
quarto render
```

El sitio se genera en `docs/`. Para publicarlo con GitHub Pages, configura Pages para desplegar desde la rama principal y la carpeta `docs/`.
